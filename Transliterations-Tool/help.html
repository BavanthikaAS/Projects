Help & Tutorials

Learn how to use the Transliterations Tool effectively

Detailed Tutorials

Text Transliteration

Step-by-Step Instructions:

  1. Navigate to the Transliteration Page: Click on "Transliterate" in the main navigation menu.
  2. Select Source Language: From the "From Language" dropdown, choose the script of your input text. If unsure, use the "Auto-Detect Language" feature.
  3. Select Target Language: From the "To Language" dropdown, choose the script you want to convert to.
  4. Enter Your Text: Type or paste your text in the input field. You can enter up to 5,000 characters.
  5. Transliterate: Click the "Transliterate" button. The AI will process your text and display the result in the output field.
  6. Copy Results: Use the "Copy Result" button to copy the transliterated text to your clipboard.

Pro Tips:

  • Use the swap button (⇄) to quickly switch source and target languages
  • The character counter helps you stay within the 5,000 character limit
  • All transliterations are automatically saved to your history
  • You can clear all fields using the "Clear All" button

OCR (Optical Character Recognition)

Extract Text from Images:

  1. Scroll to OCR Section: On the transliteration page, scroll down to the "Extract Text from Images (OCR)" section.
  2. Choose Input Method:
    • Upload File: Click "Choose File" and select an image from your device
    • Use Camera: Click "Use Camera" to take a photo directly
    • Drag & Drop: Simply drag an image file into the upload area
  3. Preview Image: The uploaded or captured image will appear in the preview area.
  4. Extract Text: Click "Extract Text" to start the OCR process. You'll see a progress indicator.
  5. Review Extracted Text: The extracted text will appear in a text area below the image.
  6. Use the Text: Click "Use This Text" to automatically fill the main input field with the extracted text.

OCR Best Practices:

  • Ensure good lighting when taking photos
  • Keep the camera steady and avoid blurry images
  • Position text horizontally for better recognition
  • Use high-resolution images for better accuracy
  • Supported formats: JPG, PNG, WebP (max 10MB)

Auto Language Detection

Automatically Identify Script:

  1. Enter Your Text: Type or paste text in the input field without selecting a source language.
  2. Click Auto-Detect: Click the "Auto-Detect Language" button below the input area.
  3. Review Detection: The system will analyze your text and suggest the most likely source language.
  4. Confirm or Adjust: If the detection is correct, proceed with transliteration. If not, manually select the correct source language.

Detection Tips:

  • Works best with longer text (more than 10 characters)
  • Confidence level is shown with the detection result
  • Mixed-script text may not be detected accurately
  • Manual selection is more reliable for short text

Frequently Asked Questions

What is transliteration?

Transliteration is the process of converting text from one script to another while preserving the phonetic pronunciation. Unlike translation, which changes meaning, transliteration maintains the sound of words.

How accurate is the transliteration?

Our tool uses AI4Bharat's IndicXlit technology, which achieves >90% accuracy in transliteration while preserving phonetic integrity across Indian languages.

Can I use this tool offline?

The tool requires an internet connection for the AI processing and OCR functionality. However, your translation history is stored locally in your browser.

What image formats are supported for OCR?

We support JPG, PNG, and WebP formats with a maximum file size of 10MB. For best results, use clear, high-resolution images with good lighting.

Is my data stored or shared?

All processing happens locally in your browser or through secure APIs. Your text and images are not stored on our servers. History is saved locally on your device.

Can I transliterate between any two supported languages?

Yes! You can transliterate between any combination of English and the 9 supported Indian language scripts in both directions (English to Indian scripts and vice versa).

What should I do if the OCR doesn't work well?

Try improving image quality: ensure good lighting, avoid blur, keep text horizontal, and use higher resolution. You can also manually type the text if OCR fails.

How do I clear my translation history?

In the history section on the transliteration page, click the "Clear History" button. This will remove all saved translations from your local storage.

Troubleshooting

Transliteration is not working

  • Check your internet connection
  • Ensure both source and target languages are selected
  • Verify that you have entered text in the input field
  • Try refreshing the page and trying again

OCR is not extracting text correctly

  • Ensure the image is clear and well-lit
  • Try rotating the image if text appears sideways
  • Use a higher resolution image
  • Check that the text is in one of the supported scripts

Camera is not working

  • Allow camera permissions in your browser
  • Ensure no other app is using the camera
  • Try refreshing the page and granting permissions again
  • Use the file upload option as an alternative

Page is loading slowly

  • Check your internet connection speed
  • Clear your browser cache and cookies
  • Try using a different browser
  • Disable browser extensions that might interfere
